# Security policy

Track Watch stores your Toggl Track API token on your phone. If you find a way to read it, or any other
security issue, please **don't open a public issue**. Report it privately via
[GitHub Security Advisories](https://github.com/ihoru/toggl-track-watch/security/advisories/new).

You'll get a reply within a week. Fixes are released as a new version, credited to you if you like.

Only the latest release is supported.
